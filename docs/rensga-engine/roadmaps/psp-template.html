PSP 2D template and Hub picker
480x272 tilemap room, 2D and 3D cards per target
1 wk
▾

The first 2D template, and the Hub's template picker. Create Project shows a 2D and a 3D card for every target API; entries that are not built yet are greyed out and name the phase that brings them. The PSP 2D template is one 480x272 tilemap room with a sprite player driven by the shared 2D platformer controller (written against Scalar, so PSX reuses it), a coin, a HUD and Camera2D. CI cooks it and boots it in headless PPSSPP.
