PSX inspector rules
Gating and validation
1.5 wk
▾

Unsupported components hidden or greyed. Validation: more than 3 lights on an object, skinned meshes (offers conversion to segmented), polygon and VRAM budget per scene, SPU RAM usage, fields too large for fixed-point range.
