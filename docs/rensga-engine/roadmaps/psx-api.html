PSX profile and fixed-point rules
What scripts can and can't do
1.5 wk
▾

ENGINE_PROFILE_PSX, feature flags, and the scripting rules: no float or double in game code (compile error with a hint), fixed literals like 1.5_fx, explicit conversions only. Same scripts compile unchanged for the PC builds of the game.

Fixed-point math API
Vector3, Quaternion, Mathf, same names
2 wk
▾

Same classes and methods as other profiles, backed by fixed-point. Angles stored in PSX units (4096 per turn) internally while the API still takes degrees. Lerp, SmoothDamp and friends rewritten to avoid overflow; Random deterministic across PSX and PC.

Rendering API on PSX
3 lights, blend modes, segmented meshes
2 wk
▾

Same Light, Material and Camera classes: 3 most relevant lights per object, fog via depth cueing, the PSX's 4 semi-transparency modes, and a SegmentedMeshRenderer that the Animator drives exactly like a SkinnedMeshRenderer. Optional sort bias on renderers to fix ordering problems.

Physics on PSX
Kinematic, simple shapes, queries
1.5 wk
▾

Same API, smaller feature set: box and sphere colliders, collision meshes for levels, CharacterController, Raycast and Overlap. Rigidbody supports gravity and simple response but no stacking solver. Unsupported options are gated in the inspector.

Audio and music API on PSX
SPU voices, XA tracks, residency
1.5 wk
▾

AudioSource maps to SPU voices with priority stealing. AudioClips declare residency per scene so the 512 KB SPU RAM is planned at cook time. Music API plays XA tracks from CD; same calls stream files on other profiles.

Scenes and saves on PSX
Area streaming, memory card blocks
1.5 wk
▾

SceneManager additive loading becomes area streaming within budget. SaveSystem writes memory card blocks (8 KB each, 15 per card) with icon and title; the API reports remaining blocks and failures. OpenBIOS lacks memory card support today, so dev builds also fall back to a host file.
