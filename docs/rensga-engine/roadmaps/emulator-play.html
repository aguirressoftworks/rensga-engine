Emulator Play button

A Unity-style Play button that builds the project and runs it in the bundled PCSX-Redux, PPSSPP or PCSX2. Emulators run as separate processes, which keeps their GPL licenses separate from the MIT editor.

Emulator launch contract
CLI args, sandboxed configs, BIOS

For each pinned emulator: the command line to boot a file directly, a per-project config folder so play sessions never touch the user's own emulator settings, a per-project memory card, and BIOS handling (OpenBIOS default for PCSX-Redux, none for PPSSPP, user dump prompt for PCSX2).

Play, Pause, Stop
Toolbar buttons driving the emulator
1.5 wk
▾

Play runs a development build for the project's console and launches its emulator; the toolbar shows Building, Launching, Running. Stop closes the emulator process. Pause and frame step use the emulator's own pause where it exposes one. A dropdown next to Play switches between Play in editor (PC preview) and Play on console.

Fast iteration path
Skip disc images, load assets from host
1.5 wk
▾

Play never builds an ISO, EBOOT or BIN/CUE: emulators boot the executable directly, and the game reads cooked assets from the project folder through each emulator's host filesystem. Only changed assets get recooked, so Play after a small change takes seconds.

Console log and crash handling
Game output in the editor console
1 wk
▾

The game's log output is captured from the emulator and shown in the editor console with the same filters as editor logs. If the emulator crashes or the game hangs, the editor reports it, saves the last log, and offers to relaunch with the emulator's debugger open.

Docked Game view
Emulator window inside the editor
2 wk
▾

On Windows and X11, the emulator window is reparented into the Game view panel so it looks embedded, with input focus following the mouse. Wayland doesn't allow reparenting, so there it falls back to a floating window positioned over the panel.

In-view emulation (optional)
Emulator renders into the Game view
3 wk
▾

True Unity feel: load an emulator core as a library and draw its frames into the Game view texture. Libretro builds exist for some of these emulators, but PSX would need a different core than PCSX-Redux, and loading GPL code into the editor process needs a licensing review before shipping.
