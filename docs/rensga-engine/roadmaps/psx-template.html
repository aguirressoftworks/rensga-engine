PSX template project

Primitive character, primitive test level and a fixed-point third-person controller, plus a 2D tilemap room. Everything is vertex-colored or CLUT4, so the scenes use almost no VRAM.

PSX primitive settings
Low tessellation, vertex color, fixed-point
0.5 wk
▾

The PSX ConsoleTarget sets primitive tessellation low (a sphere around 40 triangles), vertex colors instead of textures, and fixed-point vertex data. Primitives cook like any other mesh.

Segmented primitive character
Box body, sphere head, cylinder limbs
1 wk
▾

A prefab built as a hierarchy of primitives: torso, head, upper and lower arms and legs, each a rigid piece, which is exactly a PSX segmented model. Idle, walk and jump as transform animation clips driven by an Animator.

Primitive test level
Grid ground, platforms, ramps, pickups
1.5 wk
▾

Ground built from a grid of small tiles (big polygons warp and clip badly on PSX), platforms, ramps, stairs, walls and spinning pickups. 3 lights, depth-cue fog, one 4-bit checker texture to show how texture pages appear in the VRAM map.

Fixed-point character controller
Move, jump, camera, pickups
1 wk
▾

The shared controller script compiled for the PSX profile: camera-relative movement on the DualShock analog stick with D-pad fallback, jump with coyote time, camera orbit on L1/R1, pickup counter on screen. Sort bias on the character so it never sorts behind the ground.

Package the PSX template
3D entry, CI boot test
0.5 wk
▾

The project becomes the PSX 3D entry in the new-project dialog with a thumbnail (the Hub shows a 2D and a 3D card per target API). CI builds it and boots it in PCSX-Redux with OpenBIOS on every engine change, so the template never breaks.

PSX 2D template
320x240 tilemap room, CLUT4 tiles, fixed-point
1 wk
▾

The PSX 2D entry of the new-project dialog, made after the 2D slice runs on PSX (PSX Engine 6). One 320x240 tilemap room with 4-bit CLUT tiles, a sprite player driven by the shared 2D platformer controller (written against Scalar, so it runs in 20.12 fixed-point here), a coin, a HUD and Camera2D. CI cooks it and boots it in PCSX-Redux with OpenBIOS.
