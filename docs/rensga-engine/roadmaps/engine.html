Core and platform layer
Loop, memory, input, files, logging
3 wk
▾

Fixed-timestep loop, arena and pool allocators with a hard memory budget per target (PS2: 32 MB total, shared with code and IOP buffers). Input mapped to one virtual gamepad. File paths abstracted: cdrom0:/host:/mass: on PS2, asset folder on PC, APK assets on Android. All math in float.

2D renderer
gsKit backend + GL/GLES backend
4 wk
▾

High-level renderer interface (sprites, tilemaps, text, rects), two backends behind it. Fixed virtual resolution 640x448 scaled on PC and Android. PS2 side needs a VRAM manager: framebuffers eat most of the 4 MB, textures are uploaded per frame as needed.

Asset pipeline
C++ cooker, per-target formats, pack files
3 wk
▾

Host tool built in the same CMake tree. Source assets (PNG, WAV, glTF, JSON) cooked into one pack file per target. PS2 gets 4/8-bit paletted textures and smaller audio; PC and Android get RGBA. Runtime loads packs with zero parsing.

3D renderer
ps2gl backend + matching GL look
8 wk
▾

Meshes from glTF via the cooker (strips, quantized verts), camera, frustum culling, per-vertex lighting and fog. ps2gl gives VU1-accelerated transform without writing microcode. The GL backend deliberately mimics the PS2 look so both builds match.
