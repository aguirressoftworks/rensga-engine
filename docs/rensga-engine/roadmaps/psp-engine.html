2 wk

GU 2D backend
Display lists, 2 MB VRAM, 480x272
3 wk
▾

New gu/ render backend behind the existing interface. GU builds display lists the GPU consumes asynchronously, so the CPU fills next frame's list while the GPU draws this one. VRAM is 2 MB: two 16-bit framebuffers plus depth fit with room for hot textures; the rest stream from RAM.

GU 3D backend
Hardware T&L, lights, skinning, clipping
5 wk
▾

Easier than PS2: the GU does transform, up to 4 hardware lights and up to 8-bone skinning itself. The trap is clipping: the GU only rejects polygons outside a guard band, so large polygons crossing the near plane glitch. Fix by culling and splitting near-camera geometry on the CPU.
