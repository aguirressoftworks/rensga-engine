Rensga Engine

Open-source engine, editor and API for making games that ship as PSX, PSP and PS2 disc images plus native Windows, Linux and Android builds. Its icon is a pequi fruit, from the cerrado of Goiás, Brazil.

Shared

One engine, editor and API for every console.

Engine: shared core + PS2C++17 engine that builds the same game for PS2, Windows, Linux and Android. Later roadmaps turn phases 0-6 into the shared core for every console.~36 weeks · 10 phasesEditorUnity-style editor in C++ (Dear ImGui on SDL2 + OpenGL). Users assemble scenes, write C++ Behaviour scripts and build a playable console image or PC build.~55 weeks · 16 phasesScripting APIUnity-style C++17 API: Unity names, getters and setters instead of properties, Ref<T> handles, no exceptions, no per-frame allocation. One API for every profile, gated by the ConsoleTarget.~33 weeks · 14 phases

PSX

Minor features

Emulator Play button and the three template projects.

Emulator Play buttonA Unity-style Play button that builds the project and runs it in the bundled PCSX-Redux, PPSSPP or PCSX2. Emulators run as separate processes, which keeps their GPL licenses separate from the MIT editor.~7 weeks · 6 phasesPSP template projectBuilt first, so it carries the shared primitive generator and controller. Shows off hardware textures, lighting and a one-nub camera scheme.~5.5 weeks · 5 phasesPSX template projectPrimitive character, primitive test level and a fixed-point third-person controller. Everything is vertex-colored, so the scene uses almost no VRAM.~4.5 weeks · 5 phasesPS2 template projectThe roomiest template: smoother primitives, a dual-analog camera, rumble and a blob shadow.
