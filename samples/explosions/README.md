# Explosions (F6.09 exercise)

Click-spawned particle explosions with camera shake: the rendering API of API 7 in one small 3D scene. Everything here is generated by
`tools/make_sample.py` (cubes, flat colours and one procedural glow texture; nothing is ripped). `Assets/Scripts/Explosions.cpp` is the
one hand-written file.

| Part | What it shows |
| --- | --- |
| Pointer to world | `Camera::ScreenPointToRay` plus the ground plane turns the mouse (desktop), the nub and South (PSP) or the bot's fixed screen points into a world point; `Camera::WorldToScreenPoint` gives the pixel back (`back=` in the log) |
| Second camera | `MiniMap`: orthographic, depth 1, viewport rectangle in the top-right corner, its own clear color, and a culling mask that leaves out layer 8 (the red `Tower`) |
| `ParticleSystem` | each explosion is Fire, Smoke and Sparks from a pool of 6 sets; shapes sphere, hemisphere and cone, colour and size over lifetime, gravity, a soft glow texture; the storm at the end of the bot run emits far beyond `maxParticles` so the pools sit at capacity |
| `MaterialPropertyBlock` | the five crates share one material; the script tints each crate near a blast with a block (no material is copied) |
| `LineRenderer`, `Debug::DrawLine` | the yellow ring follows the last blast; the red beam is a `Debug::DrawLine` (dev builds only) |
| Point light | `BoomLight` flashes at every blast; its falloff is the one curve of `lighting.h` on GL and GU |
| Camera shake | `LateUpdate` moves the camera by a decaying pseudo-random offset |

Scenes: `Explosions` (manual) and `ExplosionsBot` (the bot clicks eight screen points, then runs the storm; the AUTOSTART scene of the PSP run).

```bash
python3 samples/explosions/tools/make_sample.py             # regenerate the project (Explosions.cpp is kept)
tools/ci/explosions.sh [linux] [desktop] [psp]              # headless log checks, GL screenshots (--fixed-dt: frame N = fixed step N), PSP ELF in PPSSPPHeadless with frame dumps
```

Log lines (`rensga: fx ...`): `ready`, `boom=<n> screen=<x>,<y> world=<cm x>,<cm z> back=<x>,<y> live=<n>`, `done booms=<n> live=<n> reserved=<n> rejected=<n>`.
`rejected` counts particles that did not fit a pool; it must be above 0 after the storm, and `alloc-check allocs=0` must hold.
