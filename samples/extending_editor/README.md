# extending_editor (F6.07, Editor 13)

Shows the two extension points of Editor 13 in a small PSP 3D project: editor extensions written in C++ (`Editor/`) and data assets (`Assets/Data/*.asset.json`). Docs: [editor-extensions.md](../../docs/rensga-engine/editor-extensions.md). For Unity developers: [guide-for-unity-users.md](../../docs/rensga-engine/guide-for-unity-users.md).

| File | What it is |
| --- | --- |
| `Assets/Scripts/EnemyStats.h` | the data asset type: label, kind (enum), health, speed, tint, pauses (array) |
| `Assets/Scripts/Patroller.cpp` | a component with a `Guid stats` field; reads `DataAssets::Get<EnemyStats>(stats)` in `Start` and moves between two points at `stats->speed` |
| `Assets/Data/{Grunt,Scout,Brute}.asset.json` | three EnemyStats assets (the cube colour, speed and pause come from them) |
| `Assets/Scenes/Arena.scene` | floor, camera, sun and three Patroller cubes, one per asset |
| `Editor/PatrolTools.cpp` | a custom inspector for `Patroller`, the window *Patrol Overview*, the menu items *Tools/Patrol/Line Up Selection* (`Ctrl+Shift+L`) and *Select All Patrollers* |

```bash
build/host/editor/app/rensga-editor --project samples/extending_editor
```

Things to try:

1. Select `PatrolScout`. Under the generated fields the Inspector shows **Patrol tools**: the route drawn to scale, *Swap A and B* (Ctrl+Z undoes it in one step), and the stats asset behind the `Stats` field.
2. **Window > Patrol Overview** lists every Patroller with its stats label and speed. **Tools > Patrol > Select All Patrollers**, then **Line Up Selection**: one undo step.
3. Select `Assets/Data/Scout.asset.json` in the Project window. Change *Speed*; Play; the cube moves at the new speed. Undo and Redo are in the Inspector.
4. **Project > Create > Data Asset > EnemyStats** makes a new asset with the defaults. Drag it onto a Patroller's *Stats* field.
5. Edit `Editor/PatrolTools.cpp` (for example the text *Patrol tools*), save: the console says `editor extensions changed: compiling Editor/ in the background`, then `extensions: 1 inspector(s)...`, and the Inspector changes without restarting. Make a syntax error: the Console shows the error with file and line, and the last good module stays loaded.

The project is generated by `python3 samples/extending_editor/tools/make_sample.py` (scene, assets and settings; the scripts and `Editor/` are hand-written and kept). Checks:

```bash
ctest --test-dir build/host -R "extension|data_assets|data_cook|editor_extensions_ui"    # unit tests + the editor under xvfb (screenshots in the build dir)
tools/ci/extending_editor.sh [linux] [psp] [desktop]                                      # cook the DATA section, run the scene: patrollers read their stats
```

Log lines of the run: `rensga: patroller PatrolGrunt label=Grunt kind=0 hp=30 speed_cm=200 pauses=1` and `rensga: patrol done PatrolGrunt laps=<n> x_cm=<n>`.
