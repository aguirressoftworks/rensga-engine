# platformer2d

The Engine 5 exercise: a one-room platformer on the PS2 profile (640x448). It shows the gameplay framework in `engine/core`
(`gameplay.h`, `scene_manager.h`, `save.h`) with C++ scripts in `Assets/Scripts` (Behaviour + REFLECT, like `templates/psp`).

- **Title** scene: a `UIButton` (focus + south button) whose `OnUIClick` loads the room with `SceneManager::LoadScene("Room")`.
- **Room** scene: a 20x14 `Tilemap` with a `TilemapCollider`, a player (`SpriteRenderer`, `SpriteAnimator` with idle, run and jump clips,
  `BoxCollider2D::Move`), five coin triggers, and a HUD (`UIText` coin counter, best score).
- Collecting all coins ends the run and saves the best score with `Save::SaveInt("best", ...)` (`save:/best`; on PS2 disc boots it is
  `mc0:/RENSGA/best` on the memory card).

Data files and art are generated by `tools/make_sample.py` (the output is committed). Scenes, tilemap and clips are JSON assets; the
cooker packs them into pack v2 (`TEXR`, `TMAP`, `ANIM`, `SCNE`).

```sh
cmake --preset linux-host -B build/sample -DRENSGA_PROJECT_DIR=$PWD/samples/platformer2d
cmake --build build/sample -j4 --target rensga_desktop rensga-cooker
build/sample/tools/cooker/rensga-cooker cook --project samples/platformer2d --target ps2 --force
xvfb-run -a build/sample/engine/runtime/rensga_desktop --pack samples/platformer2d/Library/Cooked/ps2/game.rpak --scene Room --frames 120 --screenshot room.png
```

Test: `ctest --test-dir build/host -R platformer` runs `tests/sample`. A bot reads the world each frame, plays title -> start -> all coins on
the real `GameLoop`, records its pad as an `InputScript`, checks the save file, then replays the script on a fresh world (same score).

PS2: `RENSGA_PS2_PROJECT=samples/platformer2d RENSGA_PS2_PACK=samples/platformer2d/Library/Cooked/ps2/game.rpak tools/ci/ps2.sh`, then
`tools/emulators/pcsx2_boot.sh build/ci/ps2/rensga.iso`. Emulator test builds can add
`RENSGA_PS2_CMAKE_ARGS="-DRENSGA_PS2_AUTOSTART=Room -DRENSGA_PS2_SAVE_SELFTEST=ON -DRENSGA_PS2_FORMAT_BLANK_CARD=ON"` (skip the title, write and
read back a save, format the blank card PCSX2 starts with).

## Audio (Engine 4)

`tools/gen_sfx.py` (stdlib only, deterministic) writes `Assets/Audio/{jump,coin,hit,save}.wav` (packed as AUDI clips, played by
the scripts through `GameState::Sfx`) and `Streaming/music.wav` (8 s loop, 22050 Hz mono). Files in `Streaming/` are not packed:
the cooker copies them next to `game.rpak` and the mixer streams them in 4096-frame double-buffered chunks as `data:/music.wav`
(PC: next to the pack; PS2: `MUSIC.WAV` on the disc root, added by `tools/ci/ps2.sh`; Android: must be in the APK assets).
Stress: `rensga_desktop --pack <game.rpak> --audio-stress --frames 600`, or PS2 `RENSGA_PS2_CMAKE_ARGS="-DRENSGA_PS2_AUDIO_STRESS=600"`.
Both log `rensga: audio-stress voices=16 mix_us=<avg>/<max>`. `ConsoleTarget.json` has `"audio": {"sampleRate", "voices"}`.
