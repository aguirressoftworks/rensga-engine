# platformer2d

The Engine 5 exercise: a single-screen-style platformer room on the PS2 profile (640x448) that runs on PS2, Windows, Linux and Android.
The room is two screens wide (1280x448) and one room: the `Camera2D` scrolls with the player. It uses the gameplay framework in
`engine/core` (`gameplay.h`, `scene_manager.h`, `save.h`) with C++ scripts in `Assets/Scripts` (Behaviour + REFLECT, like `templates/psp-3d`).

## The game

Collect all 7 coins. That clears the room: the HUD shows "ROOM CLEARED  SCORE n" and the log has `rensga: room cleared coins=7 score=<n>`.

- **Slope run**: a 45 degree slope up to a plateau, one slope down, then a ledge (tile flags `slopes` in `room.tilemap.json`).
- **One-way planks**: two planks you jump up through and stand on. Down + jump drops through.
- **Walker** (purple): patrols the floor, turns at walls, ledges and its patrol limits.
- **Hopper** (green): sits, then hops forward; turns at walls and its patrol limits.
- Touching an enemy from the side costs 1 HP (3 HP, shown in the HUD), knocks you back and gives about 1.5 s of blinking
  invulnerability. At 0 HP you restart at the last save point with full HP.
- **Stomp** an enemy from above to defeat it (+200) and bounce. Each coin is +100. Clearing the room adds a time bonus.
- **Save point** (the flag): stores the best score and the coin count with `Save::SaveInt` ("best", "coins") through the save store,
  shows "GAME SAVED  BEST n", and becomes your respawn point. Clearing the room saves too. The title shows the stored best.
  Saves are files in the platform's save folder (SDL pref folder on PC and Android) and `mc0:/RENSGA/` on the PS2 memory card.
- Sounds (`jump`, `coin`, `hit`, `save`) and a streamed music loop; layers `Player`, `Enemy`, `Pickup` in `ProjectSettings/Physics2D.json`
  (enemies ignore pickups).

## Controls

| Input | Move | Jump | Start the game |
| --- | --- | --- | --- |
| Keyboard | arrow keys or A / D | Space or Z | Space or Z |
| Gamepad | D-pad or left stick | South button (the bottom face button) | South button |
| Touch (Android, or any touch screen) | left-bottom D-pad zone | right-bottom South zone | tap the South zone |

The on-screen touch overlay shows the zones on Android always, and on desktop once a finger has touched the window.
On PS2 the D-pad, left stick and the bottom face button map the same way.

## Scenes

`Title` (button), `Room` (the game), `RoomBot` (the Room plus an `AutoPilot` object that plays it with no controller: the same moves a
player makes, driven by the world state, used by the test and by emulator runs where no pad exists).

## Build and run

Data files and art are generated by `tools/make_sample.py` (stdlib only; the output is committed). Scenes, tilemap and clips are JSON assets;
the cooker packs them into pack v2.

Desktop (Linux; use the same on Windows with the `windows` preset):

```sh
cmake --preset linux-host -B build/sample-game -DRENSGA_PROJECT_DIR=$PWD/samples/platformer2d
cmake --build build/sample-game -j4 --target rensga_desktop rensga-cooker
build/sample-game/tools/cooker/rensga-cooker cook --project samples/platformer2d --target ps2
build/sample-game/engine/runtime/rensga_desktop --pack samples/platformer2d/Library/Cooked/ps2/game.rpak            # play it
build/sample-game/engine/runtime/rensga_desktop --pack samples/platformer2d/Library/Cooked/ps2/game.rpak --scene RoomBot --frames 4000 --screenshot room.png   # the pilot plays
```

Run headless GUI checks under `xvfb-run -a`. Music and sounds need the `music.wav` the cooker copies next to `game.rpak`.

PS2 (needs the cooked pack above and Docker; PS2 does not run in public CI):

```sh
RENSGA_PS2_PROJECT=samples/platformer2d RENSGA_PS2_PACK=samples/platformer2d/Library/Cooked/ps2/game.rpak tools/ci/ps2.sh   # build/ci/ps2/rensga.iso
tools/emulators/pcsx2_boot.sh build/ci/ps2/rensga.iso --frames 600      # PCSX2 with your own BIOS (see the script header)
```

For an emulator run with no controller: `RENSGA_PS2_CMAKE_ARGS="-DRENSGA_PS2_AUTOSTART=RoomBot -DRENSGA_PS2_FORMAT_BLANK_CARD=ON -DRENSGA_PS2_CHECK_FRAMES=1100"`
starts the pilot at frame 30 and formats the blank memory card PCSX2 starts with. The log then has the stomps, "saved best=700 coins=5",
`rensga: room cleared coins=7 score=...`, `rensga: save readback best=... coins=7` and `alloc-check frames=1100 allocs=0`.

Android (APK only; the phone run is manual): cook the pack as above, then `tools/ci/android.sh` writes `build/ci/android/rensga-player.apk`
with `assets/game.rpak` and `assets/music.wav`.

## Tests

`ctest --test-dir build/host -R platformer` runs `tests/sample`: tile collision, slope run, one-way planks, enemy patrols, hurt, stomp and
respawn, the save point, the camera, and the bot test. The bot test plays `RoomBot` headless (also with uneven frame times), records its pad
as an `InputScript`, checks the save store after the save point and after the clear, then replays the script on the plain `Room` scene:
same score, same stored best.

## Audio (Engine 4)

`tools/gen_sfx.py` (stdlib only, deterministic) writes `Assets/Audio/{jump,coin,hit,save}.wav` (packed as AUDI clips, played by
the scripts through `GameState::Sfx`) and `Streaming/music.wav` (8 s loop, 22050 Hz mono). Files in `Streaming/` are not packed:
the cooker copies them next to `game.rpak` and the mixer streams them in 4096-frame double-buffered chunks as `data:/music.wav`
(PC: next to the pack; PS2: `MUSIC.WAV` on the disc root, added by `tools/ci/ps2.sh`; Android: must be in the APK assets).
Stress: `rensga_desktop --pack <game.rpak> --audio-stress --frames 600`, or PS2 `RENSGA_PS2_CMAKE_ARGS="-DRENSGA_PS2_AUDIO_STRESS=600"`.
Both log `rensga: audio-stress voices=16 mix_us=<avg>/<max>`. `ConsoleTarget.json` has `"audio": {"sampleRate", "voices"}`.
